Nội dung chính

Đây là khu vực nội dung chính của trang web. Bố cục được xây dựng bằng Bootstrap Grid System để tự động thích ứng với kích thước màn hình.

Giới thiệu Bootstrap

Bootstrap là framework hỗ trợ xây dựng giao diện website nhanh chóng, đẹp mắt và tương thích với máy tính, máy tính bảng và điện thoại.

Ưu điểm của Grid System

  • Chia bố cục thành 12 cột linh hoạt.
  • Hỗ trợ thiết kế giao diện responsive.
  • Dễ dàng sắp xếp nội dung theo từng kích thước màn hình.
